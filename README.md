## ✨ About HappyGram

HappyGram is an Android messenger project with a PHP backend and a MySQL/MariaDB database.

The project aims to bring communication features together in one convenient application.

### 🚀 Project features

- 💬 Chats and messaging
- 📎 Media sharing
- 👤 User profiles
- 📞 Voice and video calls — in development and testing
- 🌐 PHP API backend
- 📱 Android application

### 🛠 Technology

- Android
- PHP
- MySQL / MariaDB
- Nginx
