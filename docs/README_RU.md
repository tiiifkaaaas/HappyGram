# 💬 HappyGram

### Современный мессенджер для простого и удобного общения.

Добро пожаловать в HappyGram — проект Android-мессенджера с серверной частью на PHP и базой данных MySQL/MariaDB.

## ✨ Возможности проекта

- 💬 Чаты и обмен сообщениями
- 📎 Обмен медиафайлами
- 👤 Профили пользователей
- 📞 Голосовые и видеозвонки (разработка и тестирование)
- 🌐 Серверный API
- 📱 Android-приложение

## 🛠 Технологии

- Android
- PHP
- MySQL / MariaDB
- Nginx

## 🚀 Статус проекта

HappyGram находится в активной разработке. Возможности и инструкции могут меняться.

## 📦 Сборка

Открой Android-проект в Android Studio и выполни:

```bash
./gradlew assembleDebug
```

## 🤝 Участие в проекте

Мы приветствуем предложения, сообщения об ошибках и улучшения через GitHub Issues и Pull Requests.

## 🔐 Безопасность

Не публикуйте пароли, токены, приватные ключи и конфигурацию рабочей базы данных.
